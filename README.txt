NEST v5 — CALENDAR + POLISH PREVIEW

Open index.html to preview Nest on Windows.

Nest 5 changes:
- Reminder Date now opens an in-app monthly calendar so you can see and tap days in the current month.
- Dark mode uses a softer charcoal/warm-gray palette instead of pitch black.
- Scrollbars are hidden while finger/mouse scrolling still works.
- Empty note/list/reminder views keep the plant emoji and show a small + add button.
- Fresh installs start with exactly one sample note: “Welcome to Nest”, pinned.
- The old sample “Saturday errands” note is automatically removed if it came from an earlier Nest preview.

The browser preview stores notes locally. The native-ios-source folder remains the path for fully offline iPhone local notifications.
